# 技术升级调研笔记（2026-11-19）

> 目标：升级「真途」母项目技术栈。本文档记录实读的论文/开源项目、可借鉴点、落地方式。
> 触发：归簇 Agent v1 的 docstring 自认短板——"词面相似度只能抓近乎同文的重复，
> 抓不了同一事件的不同说法，属于下一版"。本轮把"下一版"做掉。

## 0. 现状盘点（升级前基线）

| 模块 | 现状 | 短板 |
|---|---|---|
| 归簇 agent_cluster.py | 词袋 TF-IDF（中文 char-bigram）+ cos/containment 混合 + average-linkage，阈值 0.45，98 案例→96 簇 | 只抓**近乎同文**重复；跨语言（英↔中）、转述式（paraphrase）重复抓不到；聚类结果是保守下界 |

## 1. 实读清单

### 1.1 Multilingual Previously Fact-Checked Claim Retrieval（PFCR，EMNLP 2023）
- 链接：https://aclanthology.org/2023.emnlp-main.1027.pdf
- **是什么**：CLEF CheckThat! Task 3 的多语言版基准——给定一条新主张，从核查站已核声明库中检索"是否已被核查过、结论是什么"。方法谱系：**BM25 等 IR 算法 + 文本向量（embedding）+ reranking 组合**。
- **借鉴**：这就是我们"35 个 insufficient 事件回填"的直接方法论——先用 embedding 召回最相似的已核声明，再人工复核结论是否可迁移。论文证实 embedding 检索是该任务的主流有效做法，reranking 用于低成本 ensemble。
- **落地**：`claim_matcher.py`——已核库 = external_findings(38) + verify_packets source_grounded(61) + 标注表人工列(带 evidence_url 的行)；对 35 个 initial 簇输出 top-k 邻居 + 相似度 + 建议结论（标注"来源建议"，不冒充人工判定）。

### 1.2 CLEF CheckThat! 2024 Lab 总览（LNCS）
- 链接：http://checkthat.gitlab.io/clef2024/pdf/CLEF_2024_CheckThat_LNCS_draft.pdf
- **是什么**：事实核查流水线六大任务（check-worthiness / subjectivity / **claim matching** / evidence retrieval / veracity / authorities）15 语言年度评测。
- **借鉴**：验证了我们三层管线的任务分解与国际主流一致；任务 3（claim matching）就是我们"已核簇直接套用"的自动化版本。后续每年 overview 可作为方法雷达。

### 1.3 FACT5（FEVER Workshop @ ACL 2025）
- 链接：https://aclanthology.org/2025.fever-1.8/ ；代码：https://github.com/shayantist/FACT5/
- **是什么**：开源端到端 LLM 核查管线——**陈述 → 原子主张分解 → 生成针对性问题 → web 检索证据 → 有依据的判定**（Mistral-7B / Gemini-1.5-Flash 实测，MSE 显著下降）。
- **借鉴**：它的四步与我们的核查 Agent 逐层同构，但把"检索什么"变成了**由主张生成的针对性问题**——这可直接用于我们 35 个 insufficient 事件的检索式自动生成（现在卡上的检索式是人工写的）。
- **落地（二期）**：给 agent_verify 加 `suggest_queries` 动作：对每个 insufficient 簇由主张变体生成 2-3 条检索式。

### 1.4 FActScore（EMNLP 2023）
- 链接：https://aclanthology.org/2023.emnlp-main.741/
- **是什么**：长文事实性评估 = 分解成原子事实 → 逐条对照可靠知识源 → supported 比例。
- **借鉴**：**原子化分解**思想——《真途卡》一个簇的"体检结论"可以按原子主张拆开逐条给证据，而不是一段笼统描述。影响出卡 schema v2 设计。

### 1.5 FacTool（2023, tool-augmented）
- 链接：https://www.semanticscholar.org/reader/7a5b44ea10a51708e18786595c8d70b18950da11
- **是什么**：LLM 事实性检测的工具增强框架：claim extraction → 逐条调用工具（检索/计算）→ 聚合判定。
- **借鉴**：主控-工具循环的形态与我们"调度主控+四 Agent"一致；它验证了"LLM 只做主张分解与聚合，事实判断交工具/来源"的分工——与我们"来源归属、不下判断"的底线一致。

### 1.6 Sentence-BERT / sentence-transformers（UKP Lab，开源）
- 项目：https://github.com/UKPLab/sentence-transformers ；模型指南（DeepWiki）：https://deepwiki.com/UKPLab/sentence-transformers/5.1-sentencetransformer-models
- **是什么**：句向量事实标准。多语言 paraphrase 系模型针对"同义改写"训练，正是归簇 v2 需要的能力。
- **选型**：`paraphrase-multilingual-MiniLM-L12-v2`（轻量 118MB，CPU 快，50+ 语言含中英）为本项目默认；`paraphrase-multilingual-mpnet-base-v2`（质量更高、~1GB）留作精度对照。
- **坑（来自实践指南）**：不同模型相似度分值不可直接互比（0.85 in MiniLM ≠ 0.85 in mpnet），阈值必须按模型重标定；embedding 落盘缓存避免重复编码。
- **落地**：`agent_cluster_v2.py`——混合相似度：语义 cos（embedding）+ 词面 containment（保留 v1 对"近乎同文"的强项），阈值曲线重标定，输出 events.v2 + 与 v1 的对比报告。

### 1.7 CLEF 2025 一支队伍的实证（佐证）
- 链接：https://www.dei.unipd.it/~faggioli/temp/clef2025/paper_56.pdf
- **结论引用**：embedding 类模型（含 SBERT）"以轻量代价拿到可接受结果"，OpenAI text-embedding-3-large 略优但外部依赖。→ 支持我们选本地 SBERT 而非外部 API（本地、免费、可复现，符合项目"可审计"底线）。

### 1.8 TDT 时间感知文档嵌入（LREC 2024，只读摘要级）
- 链接：https://aclanthology.org/2024.lrec-main.1416/
- **借鉴**：事件聚类应考虑**时间窗口**——我们 metadata 里已有采集时间，v2 可留接口（同事件不同时期版本谱系恰恰是《真途卡》需要呈现的，聚类不宜用时间硬过滤，但可作为合并证据的一个维度记录）。

## 3. 实测结论（2026-11-20 回填）

### 3.1 归簇 v2（agent_cluster_v2.py，98 案例）

- **最终设计**：sim = max(语义, 词面)；词面 ≥0.45 沿用 v1 决策（v2 ⊇ v1，零回退）；
  语义通道带标题长度门槛（双方 ≥40 字符）；阈值 0.85（精度优先）；
  **近失候选机制**：[0.75, 0.85) 的对写入 candidates 供人工复核（21 对）。
- **自动合并**：与 v1 相同的 2 对（零丢失），其中新增价值在证据质量：
  - Trump-CNN 家族（同一记者会时刻的 7-8 条转述变体）词面分仅 **0.03-0.18**
    （v1 完全不可见），语义分 0.78-0.88，全部按分数排序进入复核视野；
  - 复核通过后簇数可从 96 降至 ~88（人工一票定）。
- **踩坑记录（阈值标定三次迭代）**：
  1. 加权混合（0.6sem+0.4lex）@0.70 → 跨语言对被词面≈0 压死（上限 0.6×sem）；
  2. max() @0.70 → "FAKE NEWS!!!" 式短文本对语义虚高 0.83 误入；
  3. max() + 长度门槛 @0.85 → 精度达标，真同事件对与同主题对在 0.82-0.85 仍有重叠，
     靠候选清单人工分辨（这已是纯文本方法的上限）。
- **诚实发现**：同系列不同集（A Solid 10/11/13 Minutes，语义 0.89+）分数**高于**
  真同事件对（0.83-0.89）——纯文本 embedding 区分不了"同格式系列"与"同事件"，
  下一版需实体/频道/时间归一。本语料中该系列对被 40 字符门槛恰好挡住（标题 37 字符），
  属巧合不是保证。
- **工程坑位**：沙箱内 python 只能写仓库目录 → TMP/HF_HOME 必须指进仓库
  （`.tmp_pip` / `.hf_cache`）；HF 直连被掐 → 本地代理 + 断点续传；
  清华镜像对 pip 解析异常，阿里云可用；hf-xet 通道卡死 → `HF_HUB_DISABLE_XET=1`。

### 3.2 已核事实匹配器（claim_matcher.py，CheckThat Task3 形态）

- 已核库 66 条（external_findings 38 + verify_packets source_grounded 证据）；
- **24/35 个 initial 簇拿到 top-5 候选匹配**，11 簇无近邻（需真检索而非家族套用）；
- 抽检：高相似（≥0.7）对合家族（Trump→E18/E19），低相似（0.55-0.65）多为同主题
  不同事件（PBS/BBC 科普类）——与设计一致：候选给足，人工一票否决；
- 纪律不变：匹配结果只是"来源建议"，回填仍走 external_findings 人工确认路径。
